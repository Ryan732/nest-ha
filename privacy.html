Privacy Policy

Last updated: September 2026

This Privacy Policy describes how the Home Assistant Nest Integration ("the Application") handles information. The Application is a personal, self-hosted project operated by a single individual for private home automation use.

Who this applies to

The Application is used only by its owner. It is not offered to the public, has no additional users, and is not a commercial service.

Information the Application accesses

With the owner's explicit authorization through Google's OAuth consent flow, the Application accesses data from the owner's own Google Nest devices via the Google Smart Device Management API. This may include device status, sensor readings (such as temperature), and device controls for the owner's own thermostat, cameras, or doorbell.

How the information is used

Device data is used exclusively to display device status and enable control within the owner's private Home Assistant installation. Data is processed locally on the owner's own hardware.

Data sharing

The Application does not sell, share, transfer, or transmit any accessed data to any third party. No data is sent to the developer or to any external server beyond the owner's own Home Assistant instance and Google's own APIs.

Data retention

Any device data retained is stored only within the owner's private Home Assistant installation, under the owner's control, and can be deleted by the owner at any time.

Google user data

The Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the Application's access at any time via their Google Account permissions page.
